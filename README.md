# 做选品、找选题，还在一条条翻小红书评论？我做了个工具

刷了几十篇小红书，评论里看到不少有用的话，最后留在表格里的没几条。

做选品想看看大家到底在嫌什么，做内容想找找大家都在问什么，时间却花在了点帖子、翻评论、复制粘贴上。

我做了个**小红书评论收集工具**，放到 GitHub 了，想用的可以直接下载。

比如你在研究“通勤双肩包”，把这个词填进去，设好要找多少篇帖子、每篇收多少条评论，点开始。它会在小红书里搜索，再逐篇打开收集评论，最后导出成 Excel 能打开的 CSV 表格。

**不用你搜完一篇、点开一篇、复制一篇。**

拿到表格之后，可以按自己的问题去找：

- 做电商：有人嫌肩带勒，有人嫌电脑放不下——这些话可以拿来核对选品和详情页有没有回答买家的顾虑。
- 做内容：一堆人都在问同一个使用问题，下一篇教程就有了方向。
- 做产品：看看大家在抱怨现有产品什么、还缺什么，再决定要不要继续做调研。

这里的“双肩包”和反馈只是举例。工具帮你收集评论，不会替你判断哪个产品一定能卖，也不会自动写分析报告。

**现在先推荐想整理小红书评论的人来试。** 小红书已经跑通过一次真实采集和表格导出；目前验证的是单篇、3 条评论的小任务，大批量效果还需要继续测试。抖音完整流程还没验证，B站暂时停用，先不把它们当卖点。

[**点这里下载**](https://github.com/huihuidawang231222-del/social-media/archive/refs/heads/main.zip) · [看看项目](https://github.com/huihuidawang231222-del/social-media)

电脑上用，Windows / macOS / Linux 都有启动方式。现在是源码版，需要先装 Node.js 22+ 和 Chrome，Windows 解压后双击 `启动V2.cmd`。[安装步骤在这里](https://github.com/huihuidawang231222-del/social-media/blob/main/v2/README.md)。

第一次采集需要正常登录小红书，之后会复用这个采集窗口的登录状态。数据保存在自己电脑上；只收集有权访问、已经加载出来的评论，不保证拿到全部评论，遇到验证码会停下来。

如果你正好每天都在翻评论，欢迎拿一个关键词试试。好不好用、卡在哪，直接在这帖下面说，**尤其想听做选品、做账号和用户研究的人用完后的反馈**。反馈时别贴账号、Cookie 或含个人信息的评论原文。
